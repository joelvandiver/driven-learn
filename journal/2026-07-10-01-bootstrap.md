# Session 01 — Bootstrapping Driven Learn

## Summary
The kickoff session for the Driven Learn daily study system. We designed and
built a self-driven learning habit powered by Claude Code skills, targeting
daily practice in Rust and PostgreSQL with room to add more topics later. We
also set up progress persistence (auto-commit) and this journal so the whole
learning history lives in the repo.

## Decisions & changes
- **Three learning skills** created under `.claude/skills/`:
  - `dl-next/SKILL.md` — generates one progressive lesson (objective, fully
    commented worked example, and easy/medium/hard problems); alternates
    Rust ↔ Postgres via a rotation; advances state.
  - `dl-grade/SKILL.md` — grades the active lesson honestly (runs code when a
    toolchain exists, reasons by hand otherwise), writes a grade report, and
    advances the learner on demonstrated mastery.
  - `dl-help/SKILL.md` — gives a progressive Socratic hint ladder (reframe →
    point → probe → sketch); never reveals the solution.
- **Curricula** as ordered 20-module roadmaps: `learning/curriculum/rust.md`
  and `learning/curriculum/postgres.md`. Lessons are generated on demand from
  the module rows, not pre-written.
- **State tracking** in `learning/state.json`: per-topic module/lesson counters,
  daily rotation, streak, and a history log.
- **Docs**: root `README.md` (how it works, how to add topics) and `CLAUDE.md`
  (conventions: single source of progress, runnable examples, never leak
  solutions, honest grading).
- **Housekeeping this session**:
  - Added a "Persist progress" step to `dl-next` and `dl-grade` so every lesson,
    submission, and grade is committed and pushed — the remote container is
    ephemeral, so progress only survives once pushed.
  - Added a `dl-log/SKILL.md` skill that writes a session journal entry (like
    this file) and commits all pending work. Reusable by scheduled reminders.
  - Created this `journal/` directory and its first entry.
